    \section[\faGears]{Monext - Confirmed Software Engineer}
    \textit{01/2021 - 04/2022}

    Technical contributions to high-volume payment acquisition systems within the PayAvenue platform, processing millions of daily transactions for major retailers and acquiring banks in a PCI DSS environment.

    \subsection{Key Responsibilities}
    \begin{itemize}
        \item Developed and maintained Spring Batch processing flows handling large-scale payment acquisition workflows, including retailer file integration, protocol conversion, aggregation processing, and outgoing bank file generation.
        \item Worked daily with banking protocols and payment standards such as CB2A, CB2C, NEXO, and JCB, including legacy hexadecimal formats, field mapping constraints, and acquiring bank-specific implementations.
        \item Contributed to secure payment-processing systems within a PCI DSS environment, including PAN tokenization, hashing mechanisms, secure exchanges, and transaction integrity constraints.
        \item Delivered new features and maintenance evolutions on critical acquisition services processing hundreds of thousands to millions of transactions per day depending on client activity and business periods.
        \item Implemented unit and integration tests, contributed to refactoring initiatives, and participated in technical discussions regarding maintainability, integration, and performance improvements.
        \item Worked directly with project managers and banking/retail stakeholders to clarify requirements, validate file format constraints, and prepare deliveries.
        \item Participated in code reviews, qualification support, integration activities, and production issue investigations alongside integration and operations teams.
        \item Contributed to Jenkins pipeline improvements and Git-based release workflows for development and qualification deployments.
        \item Developed selected administration interfaces using Vaadin alongside core backend payment-processing applications.
    \end{itemize}
